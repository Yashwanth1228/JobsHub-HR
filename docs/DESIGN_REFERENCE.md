# Design reference

## Approved direction

The current production website, https://jobshubhr.com/, is the high-level reference for faithful reproduction. An unsolicited redesign is outside scope.

The known public page set includes Home, About Us, Services, Our Blog, and Contact Us. Preserve existing content and public URLs where possible. Do not invent missing copy, achievements, reviews, metrics, business claims, or assets.

## Evidence available

The page names and design direction were supplied by the project owner. The local workspace contained no screenshots or detailed page specifications at the start of this task. No live-site visual inspection or WordPress admin inspection was performed for this documentation task.

Detailed screenshot-based specifications still need to be added. No exact measurements, colors, fonts, spacing, breakpoints, or layout details are established here.

## References to collect in an approved inspection task

- Full desktop and mobile references for every public page and relevant blog views.
- Exact page URLs and the approved content and asset inventory.
- Header, navigation, footer, reusable sections, and responsive behavior.
- Typography, colors, spacing, image crops, and dimensions measured from approved evidence.
- Enquiry form fields, required states, validation messages, submission feedback, and other interactive states.

Record source URLs, capture dates, viewport sizes, and approval status alongside future screenshots. Treat unresolved visual details as pending instead of filling them with assumptions.
